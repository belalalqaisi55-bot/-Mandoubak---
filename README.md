# مندوبك الطبي (Mandoubak Med)

تطبيق **"مندوبك الطبي"** (Mandoubak Med) هو المنصة الرسمية المعتمدة للممثل الطبي ومبيعات الأدوية والصيدليات، برعاية وإشراف **د. بلال القيسي (Dr. Belal Alqaisi)**. 
يعتمد التطبيق على بيئة عمل حديثة متكاملة (React + TypeScript + Vite + Node.js + Firebase + Capacitor) لإدارة المبيعات، الطلبيات، الزيارات الطبية، المخزون، والتقارير اللحظية.

---

## 🚀 المميزات الرئيسية
- **إدارة طلبيات الأدوية:** إنشاء وتتبع ومشاركة الطلبيات عبر واتساب ونسخ النصوص بصيغة احترافية.
- **إدارة الزيارات الميدانية:** جدولة الزيارات للصيدليات والأطباء مع تتبع الموقع والمهام.
- **الربط السحابي (Firebase & IndexedDB):** مزامنة فورية للبيانات مع دعم كامل للوضع غير المتصل (Offline Mode).
- **حاسبة الجرعات للأطفال (Pediatric Dose Calculator):** أداة طبية حسابية دقيقة لتقدير الجرعات حسب الوزن والأعمار.
- **التفاعلات الدوائية والمركبات (Drug Interactions):** مرجع علمي سريع للأطباء والصيادلة.
- **برنامج الولاء والتحفيز (Loyalty Hub):** نقاط، مكافآت، ومسابقات صيدلانية تفاعلية.
- **قارئ الباركود و QR Code:** فحص سريع لمنتجات الأدوية وإضافة الأصناف للمسودة.
- **لوحة تحكم المسؤول (Admin Analytics):** متابعة المبيعات، التقارير، والنشاط الميداني.

---

## 🛠 المتطلبات التقنية وهندسة المشروع
هذا المشروع مبني بتقنيات الويب والمنصات الحديثة:
- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Motion.
- **Backend / API:** Node.js, Express (عبر `server.ts`).
- **Database & Auth:** Firebase Firestore & Firebase Auth.
- **Mobile Wrapper:** Capacitor (جاهز للتحويل وتوليد تطبيق أندرويد APK).
- **Node.js:** الإصدار 18+ أو أحدث.

---

## ⚙️ تشغيل التطبيق محلياً

1. **تثبيت الحزم والتبعيات:**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير (Dev Server):**
   ```bash
   npm run dev
   ```

3. **بناء التطبيق للإنتاج (Production Build):**
   ```bash
   npm run build
   ```

---

## 📱 بناء وتصدير تطبيق الأندرويد (APK)
التطبيق مهيأ بالكامل للعمل كـ PWA وتطبيق هجين عبر Capacitor:
- يمكنك بناء حزمة الأندرويد أو تصدير APK مباشرة من خلال سكريبت البناء:
  ```bash
  ./build-apk.sh
  ```

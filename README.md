# مندوبك الطبي (Mandoubak Med)

تطبيق **"مندوبك الطبي" (Mandoubak Med)** هو المنصة الرقمية المعتمدة لإدارة مبيعات الأدوية، جرد المخزون الدوائي، الطلبيات، والزيارات الميدانية للصيدليات والأطباء والعيادات، بإشراف **د. بلال القيسي (Dr. Belal Alqaisi)**.

يجمع التطبيق بين واجهة ويب سريعة وتطبيق هجين للأندرويد عبر بنية متكاملة تعتمد على **React 19 + TypeScript + Vite + Express + Firebase + Capacitor 8** مع دعم العمل دون اتصال بالإنترنت (**Offline-First**).

---

## 🚀 المميزات الرئيسية

- **إدارة العملاء وطلبات التسجيل الفورية:**
  - تسجيل الصيدليات والأطباء عبر رقم الهاتف أو البريد الإلكتروني أو حساب Google.
  - تنبيهات وإشعارات فورية للمندوب عند تسجيل أي عميل جديد، مع شارات تنبيه واضحة وفلترة للحسابات المعلقة والمعتمدة والموقوفة.
- **كتالوج الأصناف، الجرد الميداني، وتنبيهات نقص المخزون:**
  - عرض بطاقات الأصناف وجدول الجرد السريع مع احتساب البونص المجاني والسعر الصافي تلقائياً.
  - **شارات تحذير نقص المخزون المباشرة (`StockWarningBadge`):** تنبيه فوري للمندوب على بطاقات المنتجات عند هبوط الرصيد دون الحد المحدد (مع إمكانية تعديل حد التنبيه من الواجهة وتصفيته للأصناف الحرجة)، بالإضافة إلى **رادار العجز الحرج**.
- **إدارة الطلبيات والفواتير:** إنشاء الطلبيات وتتبع حالاتها (`pending` / `approved` / `completed`)، الطباعة، التصدير إلى CSV، والأرشفة.
- **الزيارات الميدانية والخرائط التفاعلية:** جدولة مهام الزيارات للصيدليات والأطباء وعرض المواقع على خرائط Google.
- **إدارة الاتفاقيات والشكاوى:** توثيق الاتفاقيات التجارية والبونص والعينات مع إثباتات التسليم، وإدارة شكاوى ومقترحات العملاء.
- **المساعد الذكي متعدد النماذج (AI):** دردشة ومساعد طبي عبر **Google Gemini** و **OpenRouter**، واقتراح التصنيفات الدوائية تلقائياً.
- **الأدوات الصيدلانية والسريرية:**
  - **حاسبة جرعات الأطفال (`PediatricDoseCalculator`):** حساب الجرعات بدقة حسب الوزن والعمر.
  - **التفاعلات الدوائية والمرجع الدوائي (`DrugInteractionsAndMonographs`):** فحص التداخلات الدوائية والمواد الفعالة.
  - **مركز الاختبارات الطبية (`MedicalExamHub`):** أسئلة تدريبية تفاعلية للتخصصات الطبية.
- **العمل دون اتصال والمزامنة السحابية:** تخزين محلي عبر **IndexedDB** و`localStorage` مع مزامنة تلقائية عند عودة الاتصال مع **Firebase Firestore**.
- **قارئ الباركود و QR Code:** مسح ملصقات الأدوية بالكاميرا وإضافتها للطلبية مباشرة، بجانب دعم **PWA** والتثبيت كتطبيق.

## 🛠 البنية التقنية والمكدس البرمجي

- **الواجهة الأمامية (Frontend):** React 19, TypeScript (~5.8), Vite 6, Tailwind CSS v4, Lucide Icons, Motion, Recharts, `vite-plugin-pwa`, `html5-qrcode`.
- **الخادم الخلفي (Backend API):** Node.js (>= 18), Express (`server.ts`, يُحزم عبر `esbuild` إلى `dist/server.cjs`).
- **قاعدة البيانات والمصادقة والإشعارات:** Firebase Firestore, Firebase Authentication, Firebase Cloud Messaging (FCM).
- **الذكاء الاصطناعي والخرائط:** `@google/genai`, OpenRouter API, `@vis.gl/react-google-maps`.
- **تطبيق الجوال (Android):** Capacitor 8 (`@capacitor/core`, `@capacitor/cli`, `@capacitor/android`).

## ⚙️ التشغيل والتطوير محلياً

1. **تثبيت الحزم والتبعيات:**
   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة:**
   انسخ ملف `.env.example` إلى `.env` وقم بتعبئة المفاتيح المطلوبة (مثل `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, `ADMIN_SECRET`, `VITE_GOOGLE_MAPS_API_KEY`, `VITE_FIREBASE_VAPID_KEY`, ومفاتيح OAuth عند الحاجة).

3. **تشغيل خادم التطوير (يعمل على المنفذ `3000`):**
   ```bash
   npm run dev
   ```

4. **فحص الأنواع البرمجية (TypeScript Check):**
   ```bash
   npm run lint
   ```

5. **بناء وتشغيل نسخة الإنتاج (Production Build):**
   ```bash
   npm run build
   npm start
   ```

## 📱 بناء وتصدير تطبيق الأندرويد (APK)

التطبيق مهيأ للعمل كـ PWA وتطبيق أندرويد أصلي عبر Capacitor:

- **مزامنة وبناء ملف الويب مع الأندرويد:**
  ```bash
  npm run build:android
  ```
- **بناء ملف Debug APK مباشرة عبر السكريبت:**
  ```bash
  ./build-apk.sh
  ```
- **ملاحظة لمستخدمي Termux على أجهزة Android (ARM64):**
  في حال ظهور خطأ `AAPT2 ... Daemon startup failed` أثناء البناء في Termux، ثبّت حزمة `aapt2` الخاصة بـ Termux وربط مسارها في `android/gradle.properties`:
  ```bash
  pkg install -y aapt2
  # ثم أضف إلى android/gradle.properties:
  # android.aapt2FromMavenOverride=/data/data/com.termux/files/usr/bin/aapt2
  ```

## 🔥 النشر وقواعد الأمان

- **قواعد الأمان:** مؤمّنة عبر `firestore.rules` مع تفاصيل التوثيق في `SECURITY.md`.
- **السياسات القانونية:** صفحات شروط الخدمة (`/terms`) وسياسة الخصوصية (`/privacy`) مدمجة مباشرة في الخادم.
- **نشر الاستضافة وقواعد Firestore عبر Firebase CLI:**
  ```bash
  npm run deploy:firebase
  ```

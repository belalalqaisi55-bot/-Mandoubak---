مندوبك الطبي (Mandoubak Med) - MVp

تطبيق **"مندوبك الطبي"** هو نموذج أولي (MVP) يهدف إلى تسهيل التواصل بين المندوب الطبي وعملائه (الصيدليات والأطباء). يعتمد التطبيق على بيئة عمل Firebase لإدارة الهوية، البيانات، والإشعارات اللحظية.

## 🚀 المميزات الحالية
- **تسجيل الدخول عبر الهاتف (OTP):** نظام توثيق آمن وسريع.
- **إدارة الملف الشخصي:** حفظ بيانات المندوب والمنشأة في Firestore.
- **نظام إشعارات مركزي:** إرسال تنبيهات (FCM) عبر Cloud Functions.
- **لوحة تحكم (Admin):** شاشة خاصة للمسؤول لإرسال الإشعارات الجماعية (محمية برقم هاتف المالك).

## 🛠 المتطلبات التقنية
قبل البدء، تأكد من تثبيت الأدوات التالية:
- **Flutter SDK:** الإصدار المستقر (Stable).
- **Firebase CLI:** (يحتاج Node.js) عبر الأمر `npm install -g firebase-tools`.
- **بيئة التطوير:** Android Studio مع Android SDK محدث.
- **نظام التشغيل المدعوم:** Android حالياً.

## ⚙️ إعداد المشروع

### 1) إعداد Firebase
1. اذهب إلى [Firebase Console](https://console.firebase.google.com/).
2. أنشئ مشروعاً جديداً باسم `mandoubak-med`.
3. أضف تطبيق Android باستخدام اسم الحزمة: `com.langxpharma.mandoubakmed`.
4. حمّل ملف `google-services.json` وضعه في المسار: `android/app/`.
5. **تفعيل الخدمات:**
   - **Authentication:** فعّل خيار (Phone).
   - **Firestore:** أنشئ قاعدة بيانات (بدء الاستخدام في وضع الاختبار).
   - **Cloud Messaging (FCM):** لتفعيل الإشعارات.

### 2) اختبار OTP (أثناء التطوير)
لتجنب استهلاك حصة الـ SMS المجانية:
- اذهب إلى Firebase -> Auth -> Sign-in method -> Phone.
- أضف رقم هاتف للاختبار (مثلاً: `+1 9999999999`) ورمز تحقق ثابت (مثلاً: `123456`).

### 3) إعداد المفتاح السري للإدارة (Admin Secret)
يعمل المفتاح السري كحماية مباشرة لدخول المندوب المسؤول د/ بلال القيسي وإرسال التعاميم والإشعارات المركزية.

- **المفتاح المعتمد:**
  ```text
  $
  ```
- **طريقة الضبط في البيئة السحابية (Cloud Run / Node Express):**
  يتم ضبط المتغير البيئي `ADMIN_SECRET` في لوحة الإعدادات أو ملف المتغيرات:
  ```bash
  ADMIN_SECRET="
"
  ```
- *ملاحظة:* تم دمج خادم الـ API كاملاً داخل التطبيق عبر Express وخادم الحاوية، دون الحاجة لنشر دوال منفصلة عبر `firebase deploy --only functions` أو استخدام أوامر `functions:config` الملغاة في الإصدارات الحديثة لـ Firebase.

## 🛠 طريقة الاستخدام
1. **التسجيل:** عند أول دخول، سجل برقم هاتفك.
2. **إكمال البيانات:** أدخل اسمك واسم الجهة الطبية التابع لها.
3. **لوحة المسؤول:** إذا كان رقم هاتفك هو رقم "المالك" المحدد في الكود، ستظهر لك أيقونة "الإدارة" لإرسال إشعارات لجميع المستخدمين.
4. **إرسال الإشعار:** يتطلب إدخال "المفتاح السري" الذي قمت بضبطه في Cloud Functions لضمان عدم عبث أي شخص بالخدمة.

## 🔒 ملاحظات أمنية
- **ملف الحماية:** لا تقم برفع ملف `google-services.json` إلى المستودعات العامة (GitHub).
- **المفتاح السري:** اختر `admin_secret` قوي جداً وصعب التخمين.
- **قواعد Firestore:** قبل الانتقال لمرحلة الإنتاج (Production)، تأكد من تحديث قواعد الحماية (Rules) لمنع الوصول غير المصرح به للبيانات.
